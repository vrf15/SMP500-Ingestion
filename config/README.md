\##SP500\_Ticker



This returns 500 constituents of the 503 companies within SP500. Tiingo can only return 500 a day on the free tier.



\##SP403\_Ticker



This returns all constituents of the MidCap400 plus 3 of the SP500. There was no particular reason for choosing these 3.





Because of API limitations on the free tier, I had to go with this method.
